\begin{abstract}
Zero-shot generalization for Linear Temporal Logic (LTL) specifications in reinforcement learning remains difficult because existing automaton-conditioned policies often flatten transition semantics and use static task embeddings. We propose HiLTL, a hierarchical neuro-symbolic framework that encodes semantic transition types with edge-conditioned GNN attention and decomposes value estimation into short-term dense progress and long-term acceptance signals through dynamic fusion. Experiments on continuous-control LTL benchmarks show up to +6.4\% success-rate improvement and consistent gains across tasks, supporting hierarchical temporal decomposition as an effective inductive bias for complex logical specifications.
\end{abstract}

\section{Introduction}

\IEEEPARstart{T}{he} integration of formal methods with reinforcement learning provides a foundation for verifiable autonomous systems~\citep{Baier2008}. Linear Temporal Logic (LTL)~\citep{Pnueli1977} expresses safety, liveness, and ordering constraints, but zero-shot generalization remains difficult: agents trained on limited specifications must satisfy unseen formulas without retraining.

Most LTL-RL methods translate a formula $\varphi$ into a Limit-Deterministic B\"uchi Automaton (LDBA) $\mathcal{A}_\varphi$, encode the automaton with a GNN, and condition the policy on automaton states~\citep{IcarteRewardMachines2019,deepltl}. As shown in Figure~\ref{fig:limitations}, two issues remain. First, standard message passing treats epsilon, forward, skip, and loop transitions uniformly, forcing the agent to infer their different logical roles from topology alone. Second, static automaton embeddings ignore task progress, although LTL satisfaction naturally spans local constraints, mid-horizon planning, and long-term acceptance.

\centering
\includegraphics[width=0.95\linewidth]{figure_limitations.pdf}
\caption{\textbf{Two Core Limitations.} (a) Semantic transition types (forward, skip, epsilon, backward). (b) Lack explicit guidance, causing flattening in standard GNNs. (c) Static global embeddings ignore multi-scale temporal structure, leading to myopia. HiLTL addresses both via SE-GNN semantics and hierarchical value.}
\label{fig:limitations}
\end{figure*}

This study proposes Hierarchical Long-Short-Term Temporal Logic Integration (HiLTL), shown in Figure~\ref{fig:architecture}. HiLTL combines semantically enhanced GNNs (SE-GNN), hierarchical value decomposition, and a progress-aware fusion gate that shifts credit assignment from local rewards to acceptance.

\section{Related Work}
\label{sec:related}

Neuro-symbolic RL integrates formal methods with neural policies~\citep{Jothimurugan2021}. LTL~\citep{Pnueli1977,Baier2008} can be compiled to LDBA~\citep{SafraOmegaAutomata1988,Kupferman2001} via Spot~\citep{SpotLTLTool2016}. DeepLTL~\citep{deepltl} exemplifies a strong automaton-conditioned baseline but relies on static embeddings. Recent LTL-RL methods~\citep{Vaezipoor2021,Hahn2021,bozkurt2020control} encode automata as static global embeddings or use reward machines~\citep{Icarte2022,Toro2020}, while standard GNNs~\citep{Kipf2017,Gilmer2017} often flatten transition semantics, including epsilon, forward, skip, and loops, and fail to adapt to task progress. 

Among commonly used baselines, LTL2Action~\citep{Vaezipoor2021} emphasizes formula-structure-conditioned action selection for finite-horizon tasks, while GCRL-LTL~\citep{Jothimurugan2021} adopts goal-conditioned compositional planning and is frequently used as a stronger reference on long-horizon LTL control.

Recent advances in GNN expressiveness~\citep{Dwivedi2023,sato2020survey,ying2021transformers,morris2019weisfeiler} and classic inductive message passing~\citep{Hamilton2017} provide complementary perspectives on structural encoding. Graph matching networks~\citep{li2019graph} further highlight the value of similarity-aware graph representations when structure matters across instances. Hierarchical RL~\citep{Sutton2018,Bacon2017,Nachum2018,Vezhnevets2017} learns temporal abstractions implicitly, where LTL automata can offer explicit hierarchy, while prior works underuse automaton states as progress signals toward acceptance. Certified and safe RL with logic guidance~\citep{HasanbeigCertified2021,katz2017reluplex} addresses verification, while non-Markovian rewards~\citep{Gaon2020} and interpretable policy learning~\citep{glanois2024survey} explore alternative formalisms.

\subsection{Comparative Positioning}

HiLTL differs from reward-machine methods~\citep{IcarteRewardMachines2019,Icarte2022} by learning short- and long-term value pathways end-to-end instead of relying on hand-crafted state rewards. It also differs from hierarchical RL~\citep{Bacon2017,Nachum2018}: rather than discovering temporal abstractions implicitly, it derives progress signals directly from automaton topology, improving interpretability and reducing credit-assignment burden.

\section{Preliminary}
\label{sec:problem}

\subsection{Problem Formulation}

We synthesize a policy that maximizes satisfaction probability for an LTL specification $\varphi$ on the product MDP $\tilde{\mathcal{M}}=\mathcal{M}\times\mathcal{A}_\varphi$. The environment MDP is $\mathcal{M}=(S,A,P,R,\gamma_{\text{RL}})$, where $S$ is the state space, $A$ the action space, $P(s'\mid s,a)$ the transition kernel, $R$ the reward function, and $\gamma_{\text{RL}}$ the RL discount. The LDBA is $\mathcal{A}_\varphi=(Q,\Sigma,\delta,q_0,F)$, where $Q$ is the automaton state set, $\Sigma$ the proposition alphabet, $\delta$ the automaton transition function, $q_0$ the initial state, and $F$ the accepting set. The product state is $(s,q)\in S\times Q$, and the objective is
\begin{equation}
\pi^* = \arg\max_\pi \Pr[\text{formula } \varphi \text{ is satisfied}]
\label{eq:opt_policy}
\end{equation}
For B\"uchi acceptance, the agent must visit accepting states $F$ infinitely often. The value function is

\begin{equation}
V^\pi(s,q) = \mathbb{E}^\pi\left[\sum_{t=0}^\infty \gamma_{\text{RL}}^t r_t \mid s_0 = s, q_0 = q\right]
\label{eq:value_func}
\end{equation}
Here $\pi(a\mid s,q)$ is a stochastic policy over product states and $\gamma_{\text{RL}}\in(0,1)$. We use $\text{prop}(s_t)\in2^\Sigma$ for state labels, $\delta(q,\text{prop}(s))$ for automaton updates, and $\text{dist}(q,F)=\min_{q'\in F}\text{hop-distance}(q,q')$ for progress toward acceptance.
Thus Eq.~\ref{eq:opt_policy} states the formal satisfaction objective, while Eq.~\ref{eq:value_func} gives the discounted return optimized by the RL learner on product trajectories.

\subsection{Multi-Temporal Scales in LDBA}

LDBA transitions operate at distinct temporal scales. We partition them into
\begin{equation}
\mathcal{T} = \{\tau_{\text{fwd}}, \tau_{\text{skip}}, \tau_{\epsilon}, \tau_{\text{bwd}}\}
\label{eq:transition_types}
\end{equation}
where forward chains reduce distance to $F$, skip edges provide long-range progress, $\epsilon$-transitions update logic without environment input, and backward loops maintain accepting recurrence inside strongly connected components (SCCs). This partition is later encoded in edge features, and Eq.~\ref{eq:transition_types} motivates using separate short- and long-horizon value pathways.

\subsection{Hierarchical Value Decomposition Theory}

In this study, we decompose the value function to align with temporal scales by the following convex combination,
\begin{equation}
V(s, q) = (1 - \beta(q)) \cdot V_{\text{short}}(s, q) + \beta(q) \cdot V_{\text{long}}(q)
\label{eq:decomposition}
\end{equation}
where 
\begin{equation*}
    \begin{aligned}
&V_{\text{short}}(s, q) = \mathbb{E}^\pi[r_t + \gamma_{\text{RL}} V(s_{t+1}, q_{t+1}) \mid s_t = s, q_t = q] \quad  \\
&V_{\text{long}}(q) = \Pr[\text{reach } F \mid q_t = q] \\
&\beta(q) = \sigma\left(\kappa \cdot \left(1 - {\text{dist}(q, F)}/{d_{\max}} - \theta\right)\right)
    \end{aligned}
\end{equation*}
Let $D_{\mathrm{fin}}=\{\text{dist}(q,F):q\in Q,\text{dist}(q,F)<\infty\}$ and $d_{\max}=\max D_{\mathrm{fin}}$; trap or unreachable states are clipped to $d_{\max}$ for normalization. The function $\sigma(\cdot)$ is the logistic sigmoid, $\kappa$ controls the gate slope, and $\theta$ is the inflection point. $V_{\text{long}}$ estimates the probability, under the current policy, of reaching an accepting state from automaton state $q$; for recurrent specifications this functions as a progress signal that is complemented by accepting-visit evaluation. The gate moves from short-term rewards when far from acceptance to long-term satisfaction near $F$, matching the credit-assignment structure of LTL. Figure~\ref{fig:fusion_overview} illustrates the handoff.

\section{Methodology}
\label{sec:method}

\subsection{Overview of Proposed Approach}

As shown in Figure~\ref{fig:automaton_enhanced}, HiLTL addresses semantic flattening and temporal myopia with three elements. It encodes transition types and node roles in an edge-conditioned GATv2, decomposes value into $V_{\text{short}}(s,q)$ and $V_{\text{long}}(q)$ as in Eq.~\ref{eq:decomposition}, and pools multi-scale GNN layers so local, mid-range, and global automaton structure all inform the policy.

\subsection{Semantically-Enhanced Graph Neural Networks}

\subsubsection{Graph Structure of Automaton}

Node and edge features encode automaton semantics. With $\sigma\models\varphi$ denoting satisfaction, trap states are configurations from which satisfaction is impossible. Node features ($h_v\in\mathbb{R}^4$) are
\begin{equation}
\label{eq:node_features}
h_v = [\mathbb{I}(q \in F), \mathbb{I}(q \in \text{SCC}), \mathbb{I}(q = q_0), \text{NormDist}(q, F)]
\end{equation}
where $\mathbb{I}(\cdot)$ is the indicator function, SCC marks membership in a strongly connected component, and $\text{NormDist}(q,F)=\text{dist}(q,F)/d_{\max}$. Edge features ($h_e\in\mathbb{R}^6$) are
\begin{equation}
\label{eq:edge_features}
h_e = [\mathbf{type}_{\text{onehot}}, \mathbb{I}(\text{target\_accepting}), \text{dist\_norm}]
\end{equation}
where $\mathbf{type}_{\text{onehot}}\in\{0,1\}^4$ marks forward, backward, skip, or $\epsilon$ transitions; $\mathbb{I}(\text{target\_accepting})$ marks accepting targets; and $\text{dist\_norm}=\text{dist}(q',F)/d_{\max}$ is the target's normalized distance to $F$. These features let attention distinguish progress edges, shortcuts, logical updates, and recurrence loops.

\subsubsection{Semantically-Conditioned GATv2 Mechanism}

Standard GATv2~\citep{Brody2022} attention ignores edge information:
\begin{equation}
\label{eq:gat_standard}
e_{ij}^{\text{standard}} = \mathbf{a}^T \text{LeakyReLU}(\mathbf{W} [\mathbf{h}_i \| \mathbf{h}_j])
\end{equation}

We modify this to incorporate edge semantics:
\begin{align}
\label{eq:gat_semantic}
e_{ij} &= \mathbf{a}^T \text{LeakyReLU}\left( \mathbf{W}_{\text{query}} \mathbf{h}_i + \mathbf{W}_{\text{key}} \mathbf{h}_j + \mathbf{W}_{\text{edge}} \mathbf{h}_{e_{ij}} \right) \notag \\
\alpha_{ij} &= \frac{\exp(e_{ij})}{\sum_{k \in \mathcal{N}(i)} \exp(e_{ik})}
\end{align}
In Eqs.~\ref{eq:gat_standard}--\ref{eq:gat_semantic}, $\mathbf{h}_i$ and $\mathbf{h}_j$ are source and target node embeddings, $\mathbf{h}_{e_{ij}}$ is the edge feature vector, and $\mathbf{a},\mathbf{W}_{\text{query}},\mathbf{W}_{\text{key}},\mathbf{W}_{\text{edge}}$ are learnable parameters. The edge term lets attention weight transition types adaptively, e.g., emphasizing progress edges far from acceptance and recurrence edges near accepting SCCs, without manual transition rules.

\subsubsection{SE-GNN Architecture Details}

The complete SE-GNN consists of three GATv2 layers with residual connections~\citep{He2016} and layer normalization~\citep{Ba2016}. Scaling GNNs to larger graphs leverages transformer-based designs~\citep{rampavsek2022recipe} and expressive message-passing architectures~\citep{brandstetter2022message}:
\begin{align}
\mathbf{x}^{(l+1)} &= \text{GATv2Conv}(\mathbf{x}^{(l)}, \text{edge\_index}, \text{edge\_attr}) \notag \\
\mathbf{x}^{(l+1)} &= \text{LayerNorm}(\text{MLP}(\mathbf{x}^{(l+1)}) + \mathbf{x}^{(l)})
\label{eq:segnn_update}
\end{align}
Here $\mathbf{x}^{(l)}$ denotes layer-$l$ node embeddings, \texttt{edge\_index} stores graph connectivity, and \texttt{edge\_attr} stores the semantic edge features. Equation~\ref{eq:segnn_update} combines semantic message passing with residual normalization. We use three GATv2 layers with four heads, residual connections, and LayerNorm. The layers capture 1-hop sub-goals, 2-hop loop patterns, and 3-hop topology; on the 5--18 state automata studied here, this covers most relevant structure while keeping training stable.

\subsection{MSGNN for Short-Term Features}

The short-term value network grounds decisions in immediate environmental rewards and next-step automaton transitions. To capture the hierarchical temporal structure of LTL, we leverage multi-scale embeddings from the SE-GNN layers.
We extract embeddings at three aggregation levels,
\begin{equation}
\mathbf{z}^{(l)}_{\text{pool}} = \text{ReadOut}(\mathbf{H}^{(l)}) \quad \text{for } l = 1, 2, 3
\label{eq:multiscale_readout}
\end{equation}
where ReadOut is learnable global attention pooling:
\begin{equation}
\label{eq:readout}
	\text{ReadOut}(\mathbf{H}) = \sum_{i=1}^{n} \text{softmax}_i(\mathbf{w}^T \text{ReLU}(\mathbf{W}_{\text{pool}} \mathbf{h}_i)) \cdot \mathbf{h}_i,
\end{equation}
where $\mathbf{H}$ is the set of node embeddings at a given layer, $n=|Q|$, and $\mathbf{w},\mathbf{W}_{\text{pool}}$ are learnable pooling parameters. Eq.~\ref{eq:multiscale_readout} extracts local, mid-range, and global automaton structure, and Eq.~\ref{eq:readout} converts each layer to a graph-level vector. Multi-scale embeddings are
\begin{equation}
\mathbf{z}_{\text{short}} = [\mathbf{z}_{\text{pool}}^{(1)}; \mathbf{z}_{\text{pool}}^{(2)}; \mathbf{z}_{\text{pool}}^{(3)}],
\label{eq:z_short}
\end{equation}
and the short-term value function processes the combined representation with the current environment state
\begin{equation}
V_{\text{short}}(s, q) = \text{MLP}_{\text{short}}([\mathbf{s}, \mathbf{z}_{\text{short}}, \mathbf{z}_{\text{GNN}}(q)]),
\label{eq:short_value_comp}
\end{equation}
where $\mathbf{s}$ encodes the environment state and $\mathbf{z}_{\text{GNN}}(q)$ embeds the current automaton state.
Equation~\ref{eq:z_short} concatenates the three temporal scales, and Eq.~\ref{eq:short_value_comp} is the short-term pathway used by the fusion rule; it remains environment-aware through $\mathbf{s}$ while retaining automaton context through $\mathbf{z}_{\text{GNN}}(q)$.

\subsection{Automaton Tracking for Long-Term Features}

Long-term features track three automaton signals: geodesic distance from $q$ to $F$, transition history $[q_0,\ldots,q_t]$ encoded by an LSTM, and acceptance proximity $\textit{proximity}(q)=1-{\textit{dist}(q,F)}/{d_{\max}}$.

The long-term value network aggregates these signals:
\begin{equation}
V_{\text{long}}(q) = \text{MLP}_{\text{long}}([\text{proximity}, \text{history\_enc}, \mathbf{z}_{\text{GNN}}(q)])
\label{eq:long_value_comp}
\end{equation}
where $\mathbf{z}_{\text{GNN}}(q)$ is the current automaton-state embedding. Equation~\ref{eq:long_value_comp} is environment-agnostic by design: distance provides a structural prior, history detects repeated sub-formula attempts, and proximity drives fusion.

\subsection{Dynamic Fusion with Adaptive Weighting}

Early trajectories need dense local guidance, while late trajectories need sparse acceptance signals. We use
\begin{equation}
\beta(q) = \sigma(\kappa \cdot (\text{proximity}(q) - \theta))
\label{eq:beta_definition}
\end{equation}
where $\sigma$ keeps $\beta(q)\in[0,1]$, $\kappa=3$ controls slope, and $\theta=0.5$ sets the midpoint. Thus $\beta$ shifts smoothly from $V_{\text{short}}$ far from $F$ to $V_{\text{long}}$ near acceptance.

\section{Conclusion}
\label{sec:conclusion}

This paper addresses semantic flattening and temporal myopia in LTL-constrained RL by aligning value decomposition with automaton topology. HiLTL improves ZoneEnv success rate by up to +6.4\% and remains effective across environments and infinite-horizon specifications. The main empirical lesson is that, on compact automata, explicit temporal hierarchy is more important than additional graph expressiveness; larger automata remain the natural next testbed for MSGNN scaling.

\section{Algorithm Specifications}
\label{app:algorithms}

Given an LDBA $\mathcal{A}=(Q,\Sigma,\delta,q_0,F)$, HiLTL first computes SCC membership and BFS distance-to-acceptance for every state. Node features are the four entries in Eq.~\ref{eq:node_features}; edge features are the one-hot transition type plus target-acceptance and normalized distance entries in Eq.~\ref{eq:edge_features}. A transition is classified as forward if it reduces distance to $F$, backward if it increases distance within recurrence structure, skip if it jumps by more than one distance level, and epsilon if it consumes no environment symbol.

During rollout, the product state maintains both $s_t$ and $q_t$. The policy receives the environment observation and formula embedding, while the critic computes
\[
V_{\text{total}}(s_t,q_t)=\beta(q_t)V_{\text{long}}(q_t)+(1-\beta(q_t))V_{\text{short}}(s_t,q_t).
\]
After each environment step, propositions update the automaton state by $q_{t+1}=\delta(q_t,\text{prop}(s_{t+1}))$. PPO optimizes the policy loss together with short- and long-term value losses. We use one-step TD targets for $V_{\text{short}}$ and episode-level returns for $V_{\text{long}}$, with $\lambda_{\text{short}}>\lambda_{\text{long}}$ to stabilize dense reward learning.


\section{Future Directions for MSGNN}
\label{app:future_directions}

The current MSGNN results are limited by compact automata. Future work should evaluate richer propositions and nested LTL formulas that produce 50+ state automata, tune GNN depth/head count/scale fusion jointly, and enrich edge attributes with proposition guards and transition necessity. A more principled co-design would route local GNN layers to $V_{\text{short}}$, SCC-level features to mid-range planning, and global topology to $V_{\text{long}}$, avoiding the negative interaction observed in the full configuration.

\section{Complexity Note}
\label{app:complexity}

Let $n=|Q|$ be the number of automaton states, $m=|E|$ the number of automaton transitions, $L$ the number of GNN layers, $K$ the number of attention heads, and $d$ the hidden dimension. Constructing distance and SCC features costs $O(n+m)$ per automaton. Each SE-GNN pass costs $O(LKmd)$ for edge attention plus $O(Lnd^2)$ for node transformations, and the hierarchical value heads add only small MLP costs per product state. Thus the method scales linearly in automaton edges for fixed $L,K,d$, while sample complexity is controlled empirically through the PPO budget reported in Section~\ref{sec:experiments}.
