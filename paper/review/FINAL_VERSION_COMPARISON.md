# Overleaf 长短终稿详细比较

本次比较对象为用户指定的网站快照 `overleaf/TLT`（长）和 `overleaf/TLT__Copy_`（短）。检查包含两个主文档全文、公式与表格块、图文引用、文献入口、逐文件哈希以及隔离编译；没有在线核验文献，没有从原始实验日志复算论文性能。全部终稿原件不修改。

## 1. 结论与规模

两版属于同一 HiLTL 工作：核心方法和实验数值相同，短版不只是机械删字，还修正符号、配置表达与部分图注。长版保留更完整算法和讨论，但也保留更多未验证预测与内部歧义。

| 项目 | 长版 TLT | 短版 TLT__Copy_ |
|---|---:|---:|
| 文档类型 | IEEEtran journal | IEEEtran conference |
| manuscript.tex 字节数 | 67,929 | 38,026 |
| 源码行数 | 915 | 587 |
| 去掉行注释后的英文 token 粗计 | 7,552 | 4,366 |
| table/table* 环境 | 13 | 13 |
| figure/figure* 环境 | 7 | 7 |
| algorithm 环境 | 3 | 0（改成文字规格） |
| equation / align 环境 | 13 / 2 | 13 / 2 |
| 隔离兼容副本最终页数 | 13 | 9 |
| ref.bib 条目计数 | 85 | 85 |

行数、字节数和 token 粗计都不等于出版字数。页数包含参考文献，且同时受 journal/conference 版式影响；仅代表本机数字引用兼容副本的编译结果。不能把页数减少完全归因于正文压缩。

两个文件夹各 12 个文件：只有 `manuscript.tex` 不同，其余 11 个资源完全同 SHA-256（10 个图片/PDF资源及 `ref.bib`）。详细哈希见 [protected-sources.sha256](protected-sources.sha256)，完整源码差异见 [long-short.diff](long-short.diff)。

## 2. 版式、身份与结构

标题均为 **HiLTL: Hierarchical Temporal Logic Integration for LTL Satisfaction in Reinforcement Learning**。主章节均为 Introduction、Related Work、Preliminary、Methodology、Experiments、Conclusion。

长版用 journal 类、匿名作者、Under Review 提示，并有带卷期和日期的 `markboth` 刊头。这是源码中的占位信息，不构成已确认期刊、录用或出版证明。短版采用 conference 类和 IEEEauthorblock 匿名作者。长版增加 algorithm、algorithmic、float 等包，短版去掉独立算法浮动体。

长版保留三份完整伪代码：SE-GNN 构建、Hierarchical Value Estimation、HiLTL Training。短版在 Algorithm Specifications 中压成三段文字，因此阅读实现细节需查长版，但伪代码与正文冲突处必须先核对。

长版 Future Directions 分四个方向展开，包括大图、超参数、语义与协同，并出现 8–15%、3–5%、5–8%、4–7% 等未来预期增益。这些不是已完成实验结果。短版压成简短展望并删去上述预测数字。

## 3. 方法与公式的实际变化

### 3.1 共同方法

两版都以 MDP 与 LDBA 的乘积状态 `(s,q)` 为基础，引入带节点/边语义的 SE-GNN、多层 GNN 表征、短期与长期价值、按自动机距离变化的融合权重，再结合 PPO 与分头辅助损失。两版没有替换为另一个学习算法。

### 3.2 门控符号和距离归一化

长版门控斜率使用 `γ`，容易与 RL 折扣因子混淆；短版改成 `κ`，并将折扣写成 `γ_RL`。短版更明确有限可达距离集合和 `d_max`，对不可达/trap 状态作截断说明。

长版一处写 `σ(γ*((1-dist)/max_dist-θ))`，另一处写 `σ(γ*(1-dist/max_dist-θ))`，括号位置不同，数值并不等价。短版统一为 `β(q)=σ(κ*(1-dist/d_max-θ))`。但短版仍需定义有限距离集合为空、`d_max=0` 的边界行为。

短版补充 `eq:z_short`、`eq:long_value_comp`、`eq:segnn_update` 等标签，使用 `notag` 精简多行编号，并解释更多符号。这些是表达和引用规范化，不能据此宣称新增性能。

### 3.3 图表示与复杂度

两版都描述 4 维节点、6 维边和 3 层/64 hidden/4 heads 的图网络。短版新增 Complexity Note：SCC/BFS 为 `O(n+m)`，GNN 为 `O(LKmd)+O(Lnd²)`，在层数、维度和头数固定时对图规模近线性。该说明是复杂度分析，没有给出本仓库完整 LDBA 图实现的运行证据。

短版自动机图注明确 4 维节点与 6 维边，并使用 `V_short(s,q)`；修正长版图注中 backward/trap 混用及 `V_short(s)` 等不一致写法。

### 3.4 长期价值解释

短版对“到达 F 一次”更谨慎，明确其作为 recurrent progress 的代理。两版都不能据有限回合中的一次接受或接受次数，直接推出 Büchi 无限次访问的严格满足概率保证。

## 5. 两版共同或各自保留的待核对问题

以下是审查发现，**没有修改任何终稿**。应先追溯真实实现和数据，再决定修订口径。

### 5.1 指标与实验叙述

1. `.933→.993` 是 **6.0 个百分点**，相对提高约 **6.43%**；文中 +6.4% 应标明相对比例。`.933→.975` 是 4.2 个百分点，相对约 4.5%。
2. φ3 `.924→.980` 是 5.6 个百分点、相对约 6.06%，不支持某些图注中的 hard 4.3%。图注 easy/medium/hard 的 1.2/2.9/4.3 与难度表的 6.0/6.3/5.6 不一致，也不支持提升随难度单调增大的结论。
3. 零样本 `.918→.957`、`.903→.944`、`.912→.951` 分别为 3.9/4.1/3.9 个百分点，相对约 4.25%/4.54%/4.28%。所谓平均约 4.3% 应明确为相对增益，并说明聚合方式。
4. 主表平均步数 baseline/hv_only/hv_track 为 231.1/237.0/235.7，细分表出现 231.3/236.8/235.5，需统一统计来源。
5. Flat 跨环境表 hv_only=.978 高于 hv_track=.976，正文若声称每个环境都 hv_track 优于 hv_only 则与表不符。
6. 去掉 tracking 的 hard 消融为 .970，而 hv_only 的 hard 为 .962，需交代其他开关、种子、训练或评估协议差异。
7. 95% CI 的计算单位、方法、跨种子还是跨回合、绝对差还是相对差不够明确；不能仅凭展示区间推断统计显著性。
8. held-out 的 constrained φ3 与主实验 φ3 同公式，需检查是否与训练/调参集合重叠，不能未经核验称该项为未见公式零样本泛化。
9. 公式对应 5/12/18 个自动机状态的说法依赖转换工具、版本和选项，需保存生成产物；长文相关工作提 Spot，附录提 Rabinizer，实际复现工具链需统一。

### 5.2 方法与数学定义

1. 按给定 `κ=3, θ=.5` 且 proximity∈[0,1]，固定门控 β 范围约 [.1824,.8176]。图注从 .15 开始不符合此固定函数；正文固定 sigmoid、设置中的 64-unit MLP 与附录 beta_net 也需统一。
2. 长版 SE-GNN 伪代码边最后一维使用未归一化 `|d'-d|`，正文描述 normalized target distance，两者不是同一特征。
3. forward/skip 按距离下降定义可能重叠、缺少优先级，自环/trap 边如何编码不清。若 `d` 为同一有向图上到 F 的无权最短距离，对任意边有 `d(q)≤1+d(q')`，因此有限距离时 `d(q)-d(q')>1` 不可能；skip 的语义需要另行明确，不能照字面实现无效类别。
4. 每个节点都属于某个 SCC，`in_SCC` 若不限定非平凡或 accepting SCC，将恒为真，无法提供所称区分信息。
5. 3 层消息传递通常只覆盖 3-hop；对 5–18 节点图不能自动保证每个节点接收全图信息。
6. 标准 GATv2 的常用库实现已可接收 edge features；论文贡献需落实为具体语义构造和使用方式，不能单凭“标准模型不看边”立论。
7. 折扣回报最大化与 LTL 满足概率最大化的等价条件未完整建立。`V_long` 到达一次 F 的概率、带历史的输入、完整回合 MC reward 目标，与无限时间满足概率之间也需区分。
8. 长期头若只依赖自动机/历史而不含环境状态，对具有不同可达性的环境状态通常不足以唯一决定到达概率，需明确其代理意义和历史信息范围。
